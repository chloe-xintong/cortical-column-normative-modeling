# Cortical Trajectory Analysis

This repository contains downstream analysis and visualization code based on cortical trajectories generated by the existing `Brain_column_builder` pipeline.

## Required outputs from `Brain_column_builder`

The downstream trajectory-level analysis currently requires the following information from the column-generation pipeline:

### 1. Cortical trajectories

For each hemisphere:

```text
<subject>_column_lh.mat
<subject>_column_rh.mat
```

These files contain the sampled cortical trajectories connecting the white-matter surface and pial surface.


### 2. White–pial correspondence

For each hemisphere:

```text
<subject>_pair_lh.mat
<subject>_pair_rh.mat
```


### 3. Cortical region labels

FreeSurfer annotation files:

```text
lh.aparc.annot
rh.aparc.annot
```

These are used to assign each cortical trajectory to a Desikan–Killiany cortical region.

### 4. Cortical thickness

Thickness information generated from the white–pial surface correspondence is used for trajectory- and region-level cortical thickness analysis.

### 5. Microstructural imaging data

Registered quantitative images such as:

```text
ADC / AD ...
QSM
```

are required for sampling microstructural values along each cortical trajectory.

The quantitative image and cortical trajectory coordinates must be in compatible coordinate spaces before profile extraction.
