# Archived QC and validation

This directory contains historical QC and validation work retained for
traceability. It is not required to run the current template-driven column
pipeline.

- `legacy_qc/`: former population bad-point and profile-QC helpers;
- `pipeline_validation/`: former cohort preprocessing QC notebooks;
- `surface_resampling/`: former surface-resampling validation helper;
- `template_registration_comparison/`: completed template-alignment and
  interpolation-method comparisons, separated by task;
- `validation/`: former bad-point, profile-stability, sampling-strategy, and
  spatial-data validation analyses.

The template-registration archive is organized as follows:

- `interpolation_order/`: O2-Column versus O3-Coordinate comparisons and
  related supplementary analyses;
- `regional_profiles/`: regional profile comparisons across the retained
  methods;
- `template_resolution/`: fsaverage versus fsaverage6 resolution analysis;
- `option1/`: supplementary boundary-disagreement and collision-group QC.
