# Validation layout

- `bad_point_cleaning/`: bad-point detection, retention analysis, formal cleaned-column output, and its Slurm submission file.
- `spatial_data/`: within-subject spatial similarity and region-boundary QC, with its Slurm submission file.
- `profile_stability/`: depth stability and regional CI/CV analyses, with its Slurm submission file.
- `sampling_strategy/`: tests comparing sampling strategies.
- `Validation of new pipline/`: end-to-end and historical pipeline validation notebooks.

Results are written outside this code directory under `/mnt/newStor/paros/paros_WORK/xintong/results/`.
