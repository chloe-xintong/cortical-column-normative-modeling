# ico4 null-adjusted E：局部 pair 数量收敛 pilot

## 配置与复现核验

- 人群固定为已有 null-adjusted E pilot 的10名年轻 CN；anchors 为 ico4，邻居为同半球 full-resolution 有效皮层，不限制 DK。
- 局部距离为 `(0,2]`、`(2,4]`、`(4,6]`、`(6,8]`、`(8,10]` mm；每个 pair seed 内按原排序嵌套取 K=30、100、300，不放回，候选不足时全部保留。
- 平台固定使用原有20–30 mm五个 bin、每 bin K≤300 的表；同一 pair seed 的平台在三个局部 K 间完全相同。
- 原缓存没有保存完整 null profiles，因此按正式 Figure 4B 流程和原 replicate seeds 精确重放原有20个随机场，没有新增 realization。同一 subject×realization 随机场同时用于所有 K 和 pair seeds。
- 新 rank-300 表的前30名逐 anchor×bin 与旧固定表核对，共核对 2,035,119 条，全部一致。10名受试者重放所得旧 K=30 `r_null` 和 `E` 的最大绝对误差均为0。
- E 仍按每个 realization 内先作各自平台校正、再作 real−null，最后跨20次取中位数。保留负值。

## 评价定义

所有比较均使用每个 anchor×distance-bin 的共同有效受试者；hemisphere×DK 汇总先在每名受试者的共同有效 anchors 上取中位数。每两条件报告：跨受试者 Pearson、Spearman，`E_A−E_B` 的共同偏移，去共同偏移后差值 SD，以及该 SD 与两条件平均 E 的受试者间 SD 之比。共同偏移同时报告有符号值和绝对值分布。人数不足或受试者间 SD 近零的位置单独标记，不强制解释相关或比值。

## 主要结果

跨三个 pair-seed 比较，anchor 级中位数如下：

| bin (mm) | K | Pearson | Spearman | centered residual / between SD | absolute common offset |
|---|---:|---:|---:|---:|---:|
| 0–2 | 30 / 100 / 300 | .997 / .998 / .998 | .976 / .988 / .988 | .090 / .073 / .073 | .0040 / .0033 / .0033 |
| 2–4 | 30 / 100 / 300 | .925 / .995 / .995 | .867 / .976 / .976 | .463 / .116 / .107 | .0152 / .0036 / .0033 |
| 4–6 | 30 / 100 / 300 | .852 / .978 / .993 | .782 / .952 / .976 | .649 / .243 / .133 | .0177 / .0059 / .0033 |
| 6–8 | 30 / 100 / 300 | .789 / .950 / .990 | .721 / .915 / .976 | .773 / .368 / .154 | .0184 / .0081 / .0033 |
| 8–10 | 30 / 100 / 300 | .741 / .924 / .988 | .661 / .879 / .964 | .856 / .451 / .177 | .0188 / .0090 / .0034 |

覆盖约为98.94%–98.98%，随 K 基本不变；缺失主要由固定平台/有效掩码决定，而不是新增 K。模板候选耗尽比例显示：0–2 mm 在 K=100 已为100%，2–4 mm 在 K=300 为100%；K=300 时 4–6、6–8、8–10 mm 的耗尽比例分别为100%、95.8%、82.0%。对应个体有效 pair 中位数为130、183、237，而不是名义上的300。

K=100→300 的同 seed 个体差异变化小于 K=30→100，但在较远局部 bin 仍非零：4–6、6–8、8–10 mm 的中位 centered residual/between-SD 分别约 .14、.24、.30；Pearson 分别约 .993、.979、.967。这说明增加 K 的收益开始递减，但不能把 K=100 与 K=300 视为完全等价。

重点区域在 K=300 均明显改善。以三个 pair-seed 比较和两半球的中位数为例，8–10 mm：entorhinal Pearson≈.997、比值≈.088；temporal pole ≈.998、.079；inferior temporal ≈.994、.123；各 cingulate 分区 Pearson 约 .990–.997、比值约 .093–.159。K=30 时同一 bin 的相关更低、残差比更高，尤以 inferior temporal 和 posterior/rostral anterior cingulate 明显。

## 诊断结论

1. **可保留距离**：在这个10人诊断中，K=300 时五个0–10 mm bin 的跨 seed 个体排序和差异均比 K=30 稳定；4–10 mm 的改善最大。0–2 mm 本身较稳定，但受几何候选限制，实际并未达到300；应作为“全候选/低 pair 数”特征解释。2–4 mm 也基本是全候选特征。
2. **是否开始收敛**：是，K=30→100 的改善大于 K=100→300；但6–10 mm 在 K=100→300 仍有可见的个体差异变化，故这里只能说趋于收敛，不能声明完全收敛或据此设通过阈值。
3. **null 前/建模前注意事项**：模型中必须保留实际有效 pair 数和候选耗尽标记；不能把名义 K=300 当作所有位置都使用300个 pair。重点颞叶、内嗅和扣带位置在 K=300 明显改善，没有依据自动排除，但结论仍受10人规模和固定20次 null 限制。
